# Hope Tracker 웹

Hope Tracker 웹 v1.3 (아이폰 앱 1.1 기준). 기록은 Firebase에 저장되며 로그인한 본인만 읽고 쓸 수 있습니다.

주소: https://assongcom-csl.github.io

## 변경 이력

### v1.3 (2026-11-04)
- 기록이 겹치면 나중에 입력한 기록이 위에 보이고, 누적 시간은 겹친 부분을 한 번만 셉니다(새 필드 `created`).
- 구글 캘린더(기본 캘린더)의 약속을 그리드에 보라색 테두리로 표시합니다. `[Happy]` 같은 말머리가 붙은 일정은 기록이라 제외합니다.
- 당일 그리드의 빈 칸을 누르고 끝 칸을 누르면, 지난 시간은 기록으로, 앞으로의 시간은 구글 캘린더 약속으로 추가합니다.
- 아이폰 앱 이식용 명세: [docs/v1.3-calendar-manual-add-spec.md](docs/v1.3-calendar-manual-add-spec.md)

### v1.2 (2026-11-04)
- 당일 타임 그리드와 주간 리뷰에서 칠해진 셀을 탭하면 그 기록의 셀이 강조되고, 제목과 시간이 담긴 말풍선이 뜨며, 아래 기록 목록의 해당 행도 강조됩니다.
- 주간 리뷰의 기록 행을 탭하면 거꾸로 그리드에서 그 기록이 강조됩니다.
- 당일 그리드에서 셀을 탭하면 바로 편집이 열리던 동작이 바뀌었습니다. 이제는 강조된 기록 행을 탭해야 편집이 열립니다.
- 아이폰 앱 이식용 명세: [docs/v1.2-tap-highlight-spec.md](docs/v1.2-tap-highlight-spec.md)
