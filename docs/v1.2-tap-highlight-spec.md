# Hope Tracker v1.2 — 그리드 셀 탭 하이라이트 (아이폰 앱 이식용 명세)

웹 v1.2(2026-11-04)에 들어간 기능입니다. 아이폰 앱을 1.2로 판올림할 때 이 문서대로 구현하면 웹과 동작이 같아집니다.
웹 구현 위치: `index.html`의 `renderGrid()`(당일 타임 그리드), `renderWeek()`(주간 리뷰), `showPop()`(공용 말풍선).

## 1. 공통 개념

- **선택(pick)**: 지금 강조 중인 기록 하나. 값은 기록 `id`, 진행 중인 작업이면 `"live"`.
- 셀 → 기록 매핑은 기존 `GridMath.cells`와 같아요(10분 셀, 반올림 규칙 동일). 각 셀은 자기를 칠한 기록의 `id`(또는 live)를 알고 있어야 해요.
- **강조 표시**
  - 선택된 기록의 셀: 테두리 1.5pt, 색은 잉크색(라이트 #1C1D21 / 다크 #ECEDEF). 다른 셀보다 앞(z-order)에 그려요.
  - 같은 그리드의 나머지 칠해진 셀: 불투명도 0.35
  - 빈 셀과 미래 셀은 그대로 둬요.
- **말풍선**: 배경은 잉크색, 글자는 표면색, 모서리 9pt, 그림자, 최대 너비 220pt
  - 1줄(굵게): 카테고리 색 사각점(7pt) + 제목. 넘치면 말줄임(…) 처리
  - 2줄(모노, 11pt, 불투명도 0.75): `HH:mm–HH:mm · N분 · 카테고리`
  - 진행 중일 때: `HH:mm– · 진행 중 · N분 · 카테고리`
  - 말풍선은 탭을 받지 않아요(아래 셀 탭을 막지 않음).
- **선택 해제**: 같은 기록의 셀을 다시 탭, 그리드·목록 바깥을 탭, 웹은 Esc 키도 포함

## 2. 당일 타임 그리드 (상단)

| 동작 | 결과 |
|---|---|
| 칠해진 셀 탭 | 그 기록을 선택. 셀 강조, 다른 셀 흐리게, 말풍선 표시. 기록 목록이 접혀 있으면 펼치고, 해당 행을 강조(테두리 1.5pt)한 뒤 화면에 보이도록 스크롤 |
| 같은 기록 셀을 다시 탭 | 선택 해제 |
| 빈 셀 탭 | 선택 해제 + 기존 토스트 `HH:mm · 기록 없음` |
| 강조된 기록 행 탭 | 기존처럼 편집 열기. 편집 중에는 선택을 유지 |
| 다른 기록 행을 탭해 편집 | 셀 선택을 해제하고, 편집 중인 기록의 셀을 강조(말풍선 없음) |
| 날짜 이동(‹ › 오늘, 주간 리뷰에서 날 선택) | 선택 해제 |

- **말풍선 위치**: 기록은 세로(한 시간 열)로 쌓이니까 **강조된 블록 전체의 오른쪽**(간격 8pt)에 둬요. 공간이 없으면 왼쪽에, 그것도 안 되면 탭한 셀의 위(공간 없으면 아래)에 둬요. 세로 위치는 블록 중앙에 맞추되 그리드 안으로 제한해요.
- **v1.1과 달라진 점**: 1.1은 셀을 탭하면 바로 편집이 열렸어요. 1.2부터는 탭하면 강조만 하고, 편집은 강조된 행을 탭해서 열어요.

## 3. 주간 리뷰

| 동작 | 결과 |
|---|---|
| 칠해진 셀 탭 | 그 날로 이동(다른 날이면 위쪽 화면도 그 날로 바뀜) + 그 기록 선택. 셀 강조, 말풍선, 아래 "M월 D일 기록" 목록의 행 강조 + 스크롤 |
| 같은 기록 셀을 다시 탭 | 선택 해제 |
| 빈 셀이나 요일 머리 탭 | 그 날 선택(기존 동작), 기록 선택 해제 |
| 아래 기록 행 탭 | 그 기록의 셀을 그리드에서 강조 + 말풍선(그 기록의 첫 셀 기준). 다시 탭하면 해제 |
| 주 이동(‹ 이번 주 ›) | 선택 해제 |

- **말풍선 위치**: 탭한 셀 위에 가운데 정렬하고, 그리드 폭 안으로 제한해요. 위 공간이 부족하면 셀 아래에 둬요.
- **행 강조**: 배경은 sunk색(#F3F4F6 / 다크 #25262B), 안쪽 테두리 1.2pt는 line색

## 4. SwiftUI 구현 힌트

- 상태: `@State var pick: String?`(id 또는 "live"), `pickSlot: Int?`, `pickDay: Date`. 당일 그리드용과 주간용을 따로 둬요.
- 셀 탭은 `onTapGesture`에서 처리해요. 바깥 탭으로 해제하려면 화면 배경에 `contentShape` + `onTapGesture { pick = nil }`
- 말풍선은 그리드 위 `overlay`에 두고, 셀 프레임은 `GeometryReader` + `anchorPreference`로 모아 위치를 계산해요. `allowsHitTesting(false)`
- 목록 스크롤은 `ScrollViewReader.scrollTo(id, anchor: .center)`
- 워치 앱은 이번 범위에서 빠져요.

## 5. 버전
