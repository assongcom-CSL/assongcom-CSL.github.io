# Hope Tracker v1.3 — 약속 표시, 겹침 규칙, 빈 칸 수동 추가 (아이폰 앱 이식용 명세)

웹 v1.3(2026-11-04)에 들어간 기능입니다. v1.2 명세(`v1.2-tap-highlight-spec.md`)를 바탕으로 해요.
웹 구현 위치(`index.html`): `Gcal`, `apptCells()`, `layers()`/`totals()`, `cellsFor()`, `renderGrid()`, `openAddSheet()`, `renderWeek()`

## 1. 기록끼리 겹칠 때: 나중에 입력한 기록이 위

- **새 필드 `created`**(ms, 입력 시각): 기록을 처음 만들 때 한 번만 넣고, 수정해도 바꾸지 않아요.
  - 작업 종료로 생기는 기록: 종료한 시각
  - 수동 추가 기록: 저장한 시각
- **우선순위 키**는 `created`가 있으면 그 값, 없으면 `start`(옛 기록 호환)예요. 키가 클수록 위에 그려요. 진행 중인 작업은 항상 맨 위예요.
- **그리드 칠하기**: 우선순위가 낮은 기록부터 칠해서, 높은 기록이 칸을 덮어써요(10분 반올림은 기존 `GridMath.cells`와 같음).
- **누적 합계(카테고리별, 주간)**: 화면에 보이는 부분만 분 단위로 세요. 겹친 시간은 위에 있는 기록의 카테고리로 한 번만 들어가요.
  - 계산법: 우선순위가 높은 기록부터 돌면서, 이미 차지된 구간을 빼고 남은 시간만 더해요.
- **Firebase**: `entries/<id>/created`를 추가로 읽고 써요.
  - 아이폰 앱이 기록을 다시 저장할 때 `created`를 **지우지 말고 보존**해야 해요. 지우면 그 기록은 start 순서로 돌아가요.
  - 웹은 DB 규칙이 `created`를 거부하면(400/401/403) 이 필드를 빼고 다시 보내요. 그 뒤로는 보내지 않아요(`localStorage ht:noCreated`).

## 2. 구글 캘린더 약속 표시

- **대상 캘린더**: assongcom@gmail.com의 기본(primary) 캘린더. 기록도 같은 캘린더에 저장돼요.
- **기록과 약속 구분**: 제목이 `[Happy]` `[Future]` `[Work]` `[Book]`으로 시작하는 일정은 Hope Tracker 기록이라 약속에서 빼요. 정규식은 `^\s*\[(Happy|Future|Work|Book)\]`, 대소문자는 구분하지 않아요. 종일 일정과 취소된 일정도 빼요.
- **칸 매핑**: 기록과 같은 10분 반올림을 써요. 한 칸에 약속이 여러 개면 먼저 시작한 약속을 보여요. 10분보다 짧은 약속도 한 칸은 차지해요.
- **표시**
  - 약속만 있는 칸(미래): 빈 칸 + **보라색 테두리 1.5pt**(`#7C5CFA`, 다크 모드 `#A68BFF`), 칸 안쪽으로 그려요.
  - 약속과 기록이 겹친 칸: 기록 색으로 칠하고 그 안쪽에 보라 테두리. 약속 시간에 실제로 한 일이 보여요.
  - 지나간 약속인데 기록이 없는 칸: 회색 칸 + 보라 테두리. 놓친 약속이 드러나요.
  - 주간 리뷰도 같아요(테두리는 1pt, 미래 칸 흐림 없이).
- **말풍선**
  - 기록 칸에 약속이 겹쳐 있으면, 기록 말풍선 아래에 구분선과 함께 `약속 · 제목 HH:mm–HH:mm` 한 줄을 더해요.
  - 주간 리뷰에서 약속만 있는 칸을 탭하면 약속 말풍선(보라 점, `HH:mm–HH:mm · N분 · 약속`)이 뜨고, 그 약속의 칸을 강조해요.
- **그리드 위 칩**: `약속 N`(그날 약속 수). 누르면 새로 받아요. 연결이 안 됐거나 만료되면 `캘린더 연결` 또는 `캘린더 다시 연결`이 떠요.
- **아이폰 앱**: EventKit으로 같은 캘린더를 읽고 같은 규칙으로 걸러요. OAuth는 필요 없어요.

## 3. 빈 칸 탭 → 기록 또는 약속 추가 (당일 타임 그리드)

| 동작 | 결과 |
|---|---|
| 빈 칸 탭(약속만 있는 칸 포함) | 범위 선택 시작. 칸에 빗금과 테두리, 말풍선 `HH:mm부터 / 끝 칸을 누르세요 · 같은 칸 = 10분`. 그 칸에 약속이 있으면 약속 줄도 보여요 |
| 아무 칸이나 한 번 더 탭(칠해진 칸 포함) | 끝 칸이 정해지고 범위가 확정돼요. 순서가 거꾸로면 뒤집고 추가 시트를 열어요 |
| 그리드 바깥 탭, Esc | 범위 선택 취소 |
| 칠해진 칸 탭(선택 중이 아닐 때) | v1.2 하이라이트 그대로 |

- **기록인지 약속인지 판단**
  - 시작 칸이 "지금 시각이 든 칸"보다 뒤면 **약속**
  - 그 외에는 **기록**. 기록의 종료가 지금 이후면 지금(분 단위 내림)으로 잘라요.
- **기록 추가 시트**: 작업, 관련 링크, 카테고리(기본값은 현재 선택된 카테고리), 시작, 종료
  - 저장하면 `{id, cat, title(비면 카테고리 이름), link, start, end, uploaded:false, deleted:false, created, modified}`
  - 검사: 시작·종료 필수, 12시간 이하, 종료는 지금 이전, 1분 이상. 겹쳐도 막지 않아요(1번 규칙으로 위에 보임).
- **약속 추가 시트**: 약속 이름(필수), 메모(선택 → 캘린더 일정의 설명), 시작, 종료
  - 이름이 `[Happy]` 같은 말머리로 시작하면 거부해요(기록과 섞이지 않게).
  - 기본 캘린더에 일정을 만들어요. 웹은 Calendar API `events.insert`, 아이폰은 EventKit을 써요.
- 아이폰 앱도 같은 방식으로 구현하면 돼요. 웹에서 추가한 기록은 Firebase로 아이폰에 들어오고, 아이폰 앱이 평소처럼 캘린더에 `[카테고리]` 말머리로 저장해요.

## 4. 웹 전용: 구글 로그인 방식

- Google Identity Services 토큰 방식(브라우저만 쓰고 서버와 시크릿이 없음), scope `calendar.events`
- 접근 토큰은 1시간이에요. 만료되면 칩이 `캘린더 다시 연결`로 바뀌고, 누르면 팝업이 잠깐 떴다가 닫혀요(처음 한 번만 동의).
- 약속은 `localStorage`에 캐시해 둬서, 연결이 만료돼도 마지막으로 받은 약속이 계속 보여요.
- 클라이언트 ID는 `index.html`의 `GCAL_CLIENT_ID`. 비어 있으면 캘린더 기능이 숨겨지고, 미래 칸 추가는 안내 문구만 떠요.
